## Glossary

**argument:** A value passed to a function when it is called.

**assignment statement:** A statement that assigns a value to a variable using `=`.

**Boolean:** A type, `bool`, with the values `True` and `False`.

**Boolean expression:** An expression that evaluates to `True` or `False`.

**bug:** An error in a program.

**built-in function:** A function provided by Python, such as `print`, `len`, or `type`.

**comment:** Text in a program that is ignored when the program runs. A comment begins with `#`.

**conditional statement:** A statement that chooses which code to run based on a condition.

**data type:** A category of values that determines what operations can be performed on them.

**debugging:** The process of finding and fixing errors in a program.

**dictionary:** A collection of key-value pairs.

**exception:** An error detected while a program is running.

**expression:** Code that evaluates to a value.

**floating-point:** A type, `float`, used to represent real numbers approximately.

**function:** A reusable block of code that performs a specific task.

**function call:** Code that runs a function.

**function definition:** A statement that creates a function. It begins with `def`.

**import statement:** A statement that makes code from a module available.

**indentation:** Leading spaces that Python uses to define blocks of code.

**index:** A number used to access an element in a sequence.

**integer:** A type, `int`, that represents whole numbers.

**keyword:** A reserved word in Python, such as `if`, `for`, or `def`.

**list:** A mutable ordered collection of values.

**loop:** A statement that repeatedly executes a block of code.

**method:** A function associated with an object.

**module:** A file that contains Python code and can be imported.

**object:** A value in Python, such as a number, string, list, or dictionary.

**operator:** A symbol that performs an operation, such as `+`, `*`, or `==`.

**parameter:** A variable in a function definition that receives an argument value.

**return value:** A value produced by a function.

**runtime error:** An error that occurs while a program is running.

**sequence:** An ordered collection of values.

**statement:** An instruction that Python can execute.

**string:** A type, `str`, that represents text.

**syntax error:** An error that prevents a program from being parsed and run.

**type conversion:** Creating a value of one type from a value of another type.

**value:** A piece of data that a program can use.

**variable:** A name that refers to a value.

**while loop:** A loop that runs as long as its condition is `True`.

## Additional Terms

**arithmetic operator:** An operator that performs arithmetic, such as `+`, `-`, `*`, or `/`.

**augmented assignment:** An assignment that combines an operation with assignment, such as `+=` or `*=`.

**block:** One or more indented statements treated as a unit.

**branch:** One possible path through a conditional statement.

**chained conditional:** A conditional statement with multiple alternatives using `if`, `elif`, and optionally `else`.

**constant:** A name whose value is intended not to change.

**counter:** A variable used to count something.

**docstring:** A string that documents a module, function, class, or method.

**element:** A value stored in a sequence or collection.

**enumerate:** A built-in function that returns an index and a value for each element in a sequence.

**f-string:** A string prefixed with `f` that can contain expressions inside braces.

**immutable:** Describes an object that cannot be changed after it is created.

**iteration:** One execution of a loop body.

**key:** The part of a dictionary entry used to look up a value.

**key-value pair:** A combination of a key and its associated value in a dictionary.

**list comprehension:** A compact way to create a list from another collection.

**local variable:** A variable that exists only inside a function.

**loop variable:** A variable that takes successive values during a loop.

**membership operator:** An operator such as `in` or `not in` that tests membership in a collection.

**None:** A special value that represents the absence of a value.

**package:** A collection of related modules.

**scope:** The region of a program where a name can be accessed.

**slice:** A selected range of elements from a sequence.

**standard library:** The collection of modules included with Python.

**traceback:** A report showing where an exception occurred.

**try statement:** A statement used to handle exceptions.

**exception handler:** Code that runs when a matching exception occurs.
